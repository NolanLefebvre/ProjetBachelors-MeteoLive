Politique de confidentialité

Dernière mise à jour : septembre 2026

1. Données collectées

Dans le cadre de l'utilisation de MétéoLive, nous collectons les données suivantes :

  • Adresse e-mail (utilisée comme identifiant de connexion)
  • Pseudonyme
  • Mot de passe (hashé avec bcrypt, jamais stocké en clair)
  • Villes favorites et notes météo
  • Ville par défaut et préférence d'unité de mesure
  • Localisation approximative par adresse IP (utilisée uniquement pour la géolocalisation automatique)

2. Utilisation des données

Vos données sont utilisées exclusivement pour :

  • La gestion de votre compte utilisateur
  • L'affichage de la météo personnalisée selon vos préférences
  • La génération de classements participatifs anonymisés

3. Partage des données

Vos données personnelles ne sont jamais vendues ni partagées avec des tiers. Seules vos notes contribuent aux classements publics de manière anonyme (ville + note moyenne, sans lien avec votre identité).

4. Durée de conservation

Vos données sont conservées tant que votre compte est actif. En cas de suppression de votre compte, toutes vos données personnelles (favoris, notes, préférences) sont définitivement supprimées.

5. Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès : vous pouvez consulter vos données depuis votre profil
  • Droit de rectification : vous pouvez modifier votre pseudo et votre ville par défaut
  • Droit à l'effacement : vous pouvez supprimer votre compte depuis la page Paramètres
  • Droit à la portabilité : vos données vous appartiennent

6. Cookies

MétéoLive n'utilise pas de cookies de tracking ou publicitaires. Un token JWT est stocké dans votre navigateur (localStorage) uniquement pour maintenir votre session de connexion.

7. Sécurité

Nous mettons en œuvre les mesures suivantes pour protéger vos données :

  • Chiffrement des mots de passe (bcrypt)
  • Authentification sécurisée par token JWT
  • Limitation des tentatives de connexion (5 tentatives/minute)
  • Protection contre les injections SQL via Doctrine ORM
  • Protection XSS native Angular
